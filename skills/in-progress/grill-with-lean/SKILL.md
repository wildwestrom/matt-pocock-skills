Call the Skill tool twice, for "grilling" and "lean-modeling".

A running Lean writer is an unsettled prerequisite: only the questions downstream of it wait. Its forced questions join the next round's frontier.

The session is done when the frontier is empty, every settled decision is in Lean that builds, and every `sorry` is an open claim or unbuilt definition the user has seen.
